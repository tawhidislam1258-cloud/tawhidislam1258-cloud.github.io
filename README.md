# Taohedul Islam - Personal Portfolio Website

A personal portfolio website for **Taohedul Islam** — 3rd Year CSE student at the **University of Asia Pacific (UAP)**, based in Segunbagicha, Dhaka.

## ✨ Features

- **Bright Warm Cream Aesthetic**: Palette featuring soft warm cream (`#FAF7F2`), crisp card containers, deep charcoal typography, and warm terracotta & sage green accents.
- **Pure HTML5, CSS3, & Vanilla JavaScript**: Zero frameworks or build dependencies required.
- **Fully Responsive**: Mobile-first design with animated hamburger drawer menu.
- **Showcased Projects**:
  - **Course Management System** (Java, OOP, Relational Database / SQL)
  - **E-Commerce Web Application** (HTML5, CSS3, JavaScript, Database Integration)
  - **Data Structures & Algorithms Repository** (C & C++)
- **Skills & Tech Stack Matrix**: Categorized cards for Languages (C, C++, Java, Python), Databases (RDBMS, SQL), Web Development, and Core Engineering Concepts.
- **Education & Volunteering Timeline**: Detailed milestones for *University of Asia Pacific*, *Katiadi Govt. High School*, and High School student volunteering initiatives.
- **Interactive Contact Section**: Contact information cards and interactive contact form with instant toast notification.

## 🚀 How to Run & Preview

1. Double-click [index.html](file:///C:/Users/shtab/Portfolio/index.html) or right-click and choose **Open with -> Google Chrome / Microsoft Edge / Firefox**.
2. Or run a lightweight local server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```

## 🌐 Easy Deployment Options

- **GitHub Pages**:
  1. Create a repository on GitHub named `portfolio` or `<username>.github.io`.
  2. Push these files to the repository.
  3. Go to **Settings > Pages > Branch: main / root** and click Save.
- **Vercel / Netlify**:
  - Drag and drop this folder directly to [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
